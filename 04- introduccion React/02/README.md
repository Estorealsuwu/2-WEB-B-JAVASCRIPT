# Lista de Compras Interactiva

Proyecto de React para practicar el manejo de arreglos en el estado con el Hook `useState`.

## Funcionalidades

- Agregar productos mediante el botón o la tecla Enter.
- Ver en tiempo real cuántos productos contiene la lista.
- Eliminar cualquier producto de forma individual.
- Evitar que se agreguen productos vacíos.
- Interfaz creada únicamente con HTML, sin CSS ni estilos inline.

## Ejecutar el proyecto

```bash
npm install
npm run dev
```

Abre la dirección local que muestre Vite en la terminal.

## Crear una versión de producción

```bash
npm run build
```
