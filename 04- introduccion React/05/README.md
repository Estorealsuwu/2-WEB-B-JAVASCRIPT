# Adivina el Número

Proyecto de React para practicar **renderizado condicional** y **composición de componentes**. El juego genera un número aleatorio del 1 al 100 y muestra pistas hasta que el usuario acierta.

## Ejecutar el proyecto

```bash
npm install
npm run dev
```

## Crear la versión de producción

```bash
npm run build
```

## Componentes

- `Game`: administra el estado y la lógica del juego.
- `InputNumber`: captura cada intento del usuario.
- `Message`: muestra el mensaje inicial, las pistas o el acierto.
- `RestartButton`: comienza una partida nueva.

El proyecto no utiliza CSS ni estilos en línea.
