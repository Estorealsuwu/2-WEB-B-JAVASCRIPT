# Tarjeta de Presentación con React

Proyecto del workshop para practicar componentes funcionales, JSX y el renderizado de información estática con React y Vite.

La aplicación no utiliza CSS, archivos de estilos ni estilos inline.

## Ejecutar el proyecto

```bash
npm install
npm run dev
```

Abre la dirección que muestre Vite, normalmente `http://localhost:5173`.

## Crear la versión de producción

```bash
npm run build
```

## Personalizar la tarjeta

Edita las constantes `nombre`, `profesion` y `mensaje` en `src/components/Tarjeta.jsx`.

## Estructura principal

```text
src/
├── components/
│   └── Tarjeta.jsx
├── App.jsx
└── main.jsx
```
